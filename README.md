> **이 저장소는 개인용 자미두수 사이트의 실제 소스코드입니다. 사이트는 이 저장소에서 그대로 배포됩니다.**
> 비밀번호, API 키, 개인 정보(이름·생일)는 코드에 없고, 배포 환경의 설정값으로만 들어갑니다.
>
> **질문과 답변이 저장되지 않는다는 걸 확인하려면 이 파일들을 보세요**
> - [`lib/claude-stream.ts`](lib/claude-stream.ts): AI 호출 코드. 맨 위 설명에 "저장하거나 로그로 남기지 않는다"는 원칙이 있고, 실제로 받은 내용을 AI에게 보내고 답을 돌려줄 뿐 어디에도 쓰지 않습니다.
> - [`app/api/ask/route.ts`](app/api/ask/route.ts): 추가 질문을 받는 서버 코드. 질문을 받아 위 함수로 넘기기만 합니다. 데이터베이스나 파일 저장 코드가 없습니다.
> - [`components/AskBox.tsx`](components/AskBox.tsx): 질문·답 기록은 브라우저 화면 상태에만 있고, 새로고침하면 사라집니다.
>
> 참고: AI 답변을 만들기 위해 질문은 Anthropic(Claude) API로 전송되며, Anthropic은 남용 방지를 위해 최대 30일 보관할 수 있습니다. 사이트 운영자가 볼 수 있는 곳에는 남지 않습니다.

# 자미두수 명반 리포트 (테스트 버전)

출생 정보(양력/음력 생년월일, 시각, 성별, 출생지)를 입력하면 자미두수 명반을 자동으로 그리고,
버튼 한 번으로 Claude가 전통 용어를 쉬운 한국어 "재미 분석 리포트"로 바꿔 줍니다.

## 실행 방법

```bash
npm install
cp .env.example .env.local   # 그리고 ANTHROPIC_API_KEY 값을 넣기
npm run dev                  # http://localhost:3000
```

API 키가 없어도 명반 생성은 됩니다. AI 리포트 버튼만 "키를 설정하라"는 안내를 보여 줍니다.

## 개인용 사이트 안내

이 저장소의 `main` 브랜치가 비밀번호로 잠근 개인용 사이트로 그대로 배포됩니다 (Vercel, Production Branch = `main`). 보이는 코드와 실제 돌아가는 코드가 같습니다. 이 저장소에 변경이 올라오면 Vercel 이 자동으로 다시 배포합니다.
- 첫 화면(`/`)에서 비밀번호를 맞혀야 명반 화면이 열립니다. 입력칸 기본값은 `lib/private-profile.ts`.
- 비밀번호는 코드에 없고 환경 변수 `PRIVATE_PASSWORD` 로만 정합니다. 비워 두면 아무도 못 들어갑니다.
- 비밀번호 확인은 서버에서 하고, 맞으면 30일 유지되는 로그인 쿠키(비밀번호가 아닌 서명값)를 줍니다. 비밀번호를 바꾸면 기존 로그인은 풀립니다.
- `proxy.ts`: 로그인하지 않으면 `/api/*`(AI 호출)도 막아서 남이 API 키를 쓰지 못하게 합니다.
- 검색엔진 차단(noindex, robots.txt). 저장소는 비공개로 유지하세요.

## AI 모델 메모

- 리포트 모델: Claude Fable 5.2 (`claude-fable-5-2`). 요금은 입력 100만 토큰당 $8, 출력 $40 (Opus 5.5의 2배).
- Fable 5.2 는 데이터 30일 보관 설정이 필요합니다. 조직이 무보관(ZDR)으로 설정돼 있으면 400 오류가 납니다.
- 모델을 바꾸려면 `app/api/report/route.ts` 의 `model` 한 줄만 고치면 됩니다.

## 개인정보 메모

- 서버는 출생 정보·질문·답변을 DB나 파일에 저장하지 않고, 본문을 로그로 남기지 않습니다. Q&A 기록은 브라우저 화면 상태에만 있습니다.
- 다만 답변 생성을 위해 Anthropic API로 전송되며, Anthropic은 API 입력·출력을 남용 방지 목적으로 일정 기간(기본 최대 30일) 보관할 수 있습니다. Fable 5.2는 무보관(ZDR) 설정에서 쓸 수 없습니다. 그래서 화면 문구는 "이 서비스에 저장되지 않는다"와 "제공사 정책에 따라 일정 기간 보관될 수 있다"를 함께 적었습니다.
- 배포 플랫폼(Vercel 등)의 접근 로그에는 요청 경로·시각 정도만 남고 본문은 남지 않는 것이 일반적이지만, 배포 시 설정을 확인하세요.

## 계산 가정 (바꿀 수 있음)

- 출생지는 한국 도시 목록 또는 경도 직접 입력. 경도로 **진태양시**를 보정해 시진을 정합니다 (서울은 약 32분 늦춰짐).
- 한국 표준시: 1954-03-21 ~ 1961-08-09 는 UTC+8:30, 그 외 UTC+9. 해외 출생은 아직 UI에 없음 (`utcOffsetMinutes` 필드는 준비됨).
- 서머타임: 1987·88년 기간은 안내만 띄우고, 체크하면 1시간을 뺍니다. 1948~60년 서머타임은 사용자가 직접 체크.
- 23시 이후(야자시)는 다음 날로 넘겨 배치 (원본 엔진 기본값).
- 윤달은 원본 엔진 기본 규칙을 따름.
- 시각을 모르면 정오(오시)로 가정하고 화면에 표시.
- 별 밝기(묘왕득리평불함)·잡성 배치는 원본 엔진 기본 유파 설정을 그대로 사용.
